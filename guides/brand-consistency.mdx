Brand consistency across a campaign means every image shares the same character, product rendering, lighting, and visual tone. Rainfrog achieves this through reference-based assets on the canvas — not by rewriting prompts for every frame.

## Why visual consistency matters

In prompt-only tools, each generation runs independently. Small wording changes can shift faces, product color, or materials. That drift makes cohesive campaigns hard.

In Rainfrog, brand DNA lives in the workflow: product image, character reference, style, and environment. Every run that keeps those nodes locked inherits the same anchors. Change pose or framing, and character and product stay aligned.

## Product anchoring

Upload your product under **Assets → Products** and select it on a Product node. Rainfrog holds shape, color, and material properties steady across runs that use that asset. For a product line, keep one Product node per SKU and swap between runs without touching the rest of the graph.

## Character consistency

Use a clear portrait — well-lit, front-facing, neutral expression when possible. Stock or custom characters both work. Rainfrog uses the reference to keep face and proportions consistent across poses, outfits, and environments.

## Style presets

Select a built-in style on the Style node, or create a custom style from reference images that capture your brand's color, lighting, and mood. Once the Style node is set, connected generators inherit that treatment.

Keep the same Style node wired when you want a full set to feel like one shoot.

## Environment locking

Define the world with an Environment node. Reusing the same environment across runs keeps background and spatial feel consistent. Lock a studio, outdoor location, or interior once and carry it through the campaign.

## Image edits with References

To refine an existing result without losing brand anchors, connect a previous image into a new Image Generator's **References** input. Keep Product, Character, Style, and Environment connected so the edit stays on-brand.

## Reviewing consistency

Review results together — not only one frame at a time. Check lighting direction, facial features, product rendering, and color temperature across the set.

If something drifts, refresh the character or product reference, tighten the Style node, and regenerate. Structural changes apply uniformly on the next run.

<Tip>
  For a seasonal campaign, lock style, environment, and character. Swap only the Product node between runs to cover every SKU with the same visual DNA.
</Tip>

<Info>
  Rainfrog leans on reference assets, not long text descriptions, to keep character and product consistent when pose or environment changes.
</Info>
