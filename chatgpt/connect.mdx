Connect Rainfrog once with a custom MCP URL. ChatGPT opens Rainfrog’s sign-in and consent screen, then you can use Rainfrog from a new chat.

<Tip>
  Rainfrog is not listed in the ChatGPT directory yet. Use the **custom MCP** steps below — do not look for a directory install.
</Tip>

## Before you start

- Sign up or sign in at [app.rainfrog.ai](https://app.rainfrog.ai)
- Confirm you have a paid plan with credits if you plan to generate ([Plans & Credits](/plans-and-credits))
- Use ChatGPT on the web with a plan or workspace that allows custom MCP connectors

<Steps>
  <Step title="Open Plugins">
    In ChatGPT on the web, open **Plugins**.
  </Step>

  <Step title="Add a custom MCP server">
    Select the **+** button, then **Add custom MCP server**. Name it **Rainfrog**. Under **Connection**, paste:

    ```text
    https://mcp.rainfrog.ai/mcp
    ```
  </Step>

  <Step title="Choose OAuth">
    Choose **OAuth**, acknowledge the risk warning, and select **Create as a plugin**.
  </Step>

  <Step title="Allow access on Rainfrog">
    Sign in to Rainfrog if prompted. On the consent screen, review what ChatGPT can access, then click **Allow**.
  </Step>

  <Step title="Start a chat">
    Start a new chat, type `@`, and select **Rainfrog**. Ask it to list your projects or start a campaign.
  </Step>
</Steps>

<Note>
  Business and Enterprise/Edu workspaces can use the full tool set when an admin allows custom MCP connections. Pro accounts can connect a custom server with read and fetch permissions.
</Note>

<Note>
  You never paste API keys or secrets into chat. Connection uses OAuth only.
</Note>

## Disconnect or limit access

- **Revoke the app:** In Rainfrog, open the dashboard → **Settings** → **Connected apps**, then remove ChatGPT (or the connector you authorized).
- **Limit agent actions:** Set each action family (**Read**, **Add**, **Edit**, **Delete**, **Generate**) to **Ask**, **Always allow**, or **Deny**. See [Control what the assistant can do](/mcp/setup#control-what-the-assistant-can-do).

After you revoke, reconnect anytime by repeating the steps above.

## Other MCP clients

The same URL works in Claude, Claude Code, Cursor, Grok Bot, and any client that supports remote Streamable HTTP with OAuth. See [Set up MCP](/mcp/setup).
